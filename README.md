# Task Manager Application

A full-stack Task Manager application built using Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features
- Add tasks
- View tasks
- Delete tasks
- Responsive modern UI

## Tech Stack
- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript

## Project Structure
- Backend: Spring Boot REST API
- Frontend: Thymeleaf Templates

## Run Locally

1. Clone the repository
2. Configure MySQL
3. Run the Spring Boot application
4. Open:
   http://localhost:8083
